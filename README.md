# 히오스 영웅 3D 뷰어 (웹판)

《히어로즈 오브 더 스톰》의 영웅 모델을 브라우저에서 돌려보는 팬 제작물입니다.
영웅 103명 · 전 스킨 · 색배합까지, 설치 없이 링크만으로 열립니다.

**→ https://sin0nis.github.io/hots_hero_m3/**

## 무엇이 들어 있나

- **영웅 목록**(`index.html`) → 영웅을 누르면 `h/<번호>_<슬러그>.html` 로 갑니다.
- 영웅 페이지에서 **스킨**과 **색배합**을 바꿔 가며 볼 수 있습니다.
- 동작은 **Stand · Walk · Dance** 세 가지입니다 (용량을 줄이려고 추렸습니다).
- 모델·텍스처는 **누를 때 받아옵니다** — 첫 화면은 가볍고, 본 것은 캐시됩니다.

## 왜 이런 구조인가

같은 자료로 만든 «낱개 HTML»(파일 하나가 완결, 더블클릭으로 열림)도 있는데,
그건 `file://` 에서 fetch 가 막혀 자료를 전부 base64 로 박아 넣습니다. 웹에는
그 제약이 없어서, 여기서는 자료를 따로 두고 필요할 때 받아옵니다 —
base64 낭비(33%)가 없고 브라우저가 캐시해 줍니다.

## 만드는 법

원본 게임 자료(추출한 `.m3`/`.dds`)가 있어야 합니다. 이 저장소에는 결과물만
들어 있습니다.

```
# 모델·동작 (텍스처 512, 동작 3개)
python ../hots_hero/tools/build_heroes.py --skins all --tex 512 \
       --anims "Stand,Walk,Dance" --out data
# 색배합
python ../hots_hero/tools/build_variations.py --tex 512 --data data
# 사이트 조립
python tools/build_web.py
```

## 못 하는 것

- **스킬 이펙트** — 게임의 이펙트는 텍스처가 시간에 따라 흐르고 파티클이 뿜어져
  나오며 액터가 자리를 잡아 주는 것이라, 메시만 세워 두면 오히려 이상해집니다.
  그래서 뺐습니다.
- **천 물리·표정 세부** — 근사만 합니다.
